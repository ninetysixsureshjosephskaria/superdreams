# Architecture Decision Records (ADR)

Permanent, individually-numbered records of significant architectural decisions.

ADRs **001–015** are recorded inline in [`docs/dna/11-product-decisions.md`](../dna/11-product-decisions.md)
(the founding platform decisions). Standalone ADR files continue that number
sequence from **016** onward and live in this directory.

| ADR                                                    | Title                                   | Status   |
| ------------------------------------------------------ | --------------------------------------- | -------- |
| 001–015                                                | Founding decisions (see DNA‑11)         | Approved |
| [016](ADR-016-frontend-compiler-tooling.md)            | Frontend compiler & tooling decisions   | Approved |

## Format

Each ADR states the **context**, the **decision**, its **consequences**, and the
**alternatives considered**. Architectural decisions are intentionally stable;
changing one requires a superseding ADR (see the change process in DNA‑11).
